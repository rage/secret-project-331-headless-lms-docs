Expand description

Implements one tool. S is the application state the protocol layer passes through, such as the database pool, config and validator client.

Provided Associated Constants§

Source

const ASKS_FOR_CONFIRMATION: bool = false

Whether call can answer ToolOutcome::NeedsConfirmation. Only then does dispatch bind the call’s arguments to a confirmation, which costs a pass over them.

Required Associated Types§

Source

type Args: DeserializeOwned + JsonSchema + 'static

The tool’s arguments; their JSON Schema is the tool’s input schema.
