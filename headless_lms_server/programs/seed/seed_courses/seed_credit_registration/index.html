Module seed_credit_registration 

Source
Expand description

Database rows for the credit-registration (Suotar) system tests. The identities they are built from, and the matching registry world, are in crate::mock_suotar::fixtures.

The workers tick every phase unscoped every few seconds in the test deployment, so a fixture row nothing may move has to sit on a paused module — that is what the states course is for.
