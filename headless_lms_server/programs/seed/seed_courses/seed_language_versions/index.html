Module seed_language_versions 

Source
Expand description

Course sets for the language version repair tool’s system tests. Each set is a Finnish course with a Swedish language version that is connected wrong (a page missing, two pages linked to the same page, a chapter in another order) and an English course copied from it as a separate course, plus a teacher who can edit all three and students enrolled in them.

Each spec gets a set of its own, in its own organization, so that join candidates and problem lists never see another spec’s courses.
