Module exercise_service_client_upload_reaper 

Source
Expand description

Removes files uploaded through the exercise-services client API that no submission was ever made from.

A client uploads immediately before submitting, so anything still unreferenced an hour later is the residue of a crashed or abandoned run. The binding row is soft-deleted rather than removed so that a submit naming a reaped file can still answer upload_expired instead of the misleading unknown_upload.
