Expand description

Copies a changed name and/or email to TMC in one write, so TMC takes both or neither. A no-op for an account without a TMC id. Send only an email the user entered on the platform: an unchanged one may be older than TMC’s.

Fails with BadRequest when TMC refuses the address, e.g. because another account uses it.
