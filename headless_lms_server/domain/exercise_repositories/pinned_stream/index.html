Module pinned_stream 

Source
Expand description

The socket stream libgit2 opens every repository-clone connection through.

Registered as libgit2’s standard stream, it carries plain http, https (libgit2’s TLS stream wraps it and still verifies the certificate) and ssh. It resolves the host once, refuses unless every address is public, and connects only to those addresses, so a DNS answer that changes between validating the name and connecting to it cannot reach a private address.
