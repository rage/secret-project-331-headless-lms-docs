sync_checkout 🔒
Updates the repository’s exercises to match found, keeping each exercise’s id: one found at the same part and name is the same exercise, and failing that one with the same checksum. Each new version gets an archive at a new path; the replaced archives are retired, not deleted, since copies of the course may still use them. On error, nothing is changed and the new archives are removed.
