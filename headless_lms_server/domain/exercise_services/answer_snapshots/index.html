Storing ungraded answer snapshots (pastes and backups) for a native client.

Structs§

SnapshotAnswer
The answer a snapshot stores. The caller has established which course exercise, slide and task it is for and that the user may view them.

Constants§

MAX_BACKUPS_PER_USER_AND_EXERCISE
How many backups of one exercise a user keeps; storing another deletes the oldest. Pastes are not counted, since each one backs a link the user has handed out.
PASTES_PER_HOUR 🔒
Pastes a user may store of one exercise per hour.
PASTES_PER_MINUTE 🔒
Pastes a user may store of one exercise per minute. Backups need no limit of their own: each one past MAX_BACKUPS_PER_USER_AND_EXERCISE deletes the oldest, so their storage stays bounded.

Functions§

store_snapshot
Stores a snapshot of the named uploads, then trims the user’s backups of the exercise to MAX_BACKUPS_PER_USER_AND_EXERCISE. A paste over the per-user, per-exercise limit is refused with 429.
