Saves the profile form and copies a changed name to TMC, where the same account signs in.

A changed email reaches TMC here only when email ownership verification is off; otherwise crate::controllers::main_frontend::email_verification::verify_email_ownership sends it once the user proves the address with a verification code. Commits only after TMC accepts, so a TMC failure leaves the profile as it was, and an address TMC refuses fails with BadRequest.
