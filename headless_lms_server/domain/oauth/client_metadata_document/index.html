Module client_metadata_document 

Source
Expand description

OAuth Client ID Metadata Documents (draft-ietf-oauth-client-id-metadata-document): a client whose client_id is an https URL is registered by fetching the JSON document at that URL.

The URL comes from whoever starts an authorization request, so fetching it must not reach internal services: the host must resolve only to public addresses, the connection is pinned to the checked addresses, redirects are not followed and the response size and time are capped.
