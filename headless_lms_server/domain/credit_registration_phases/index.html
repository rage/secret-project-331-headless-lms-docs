Module credit_registration_phases

Expand description

The thirteen credit-registration pipeline phases and the one-iteration dispatcher.

Both the worker loops and the test tick endpoint go through run_phase_once, so a phase cannot behave differently depending on who ran it.

Traits§

MailQueuePhase 🔒
A phase whose whole body is “claim rows, look up each one’s template, skip it if the template is missing, otherwise queue a mail”. link-emails and student-notifications are its only two shapes; run_mail_queue_phase is the loop they share.
SuotarBatchPhase 🔒
A phase whose iteration is “claim rows, decide in one transaction what may be asked, send one batch, write one answer per row”. import, resolve-enrolments, and each of verify’s two flows; run_suotar_batch_phase is the loop they share, and the only place the transaction shape, the moved-on skipping and the counters are written down.
