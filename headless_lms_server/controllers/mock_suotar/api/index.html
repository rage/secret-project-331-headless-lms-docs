The six contract endpoints, one stage boundary at a time.

Order per request: credential, parse, item-keyed load, the auth/requestGate/parse faults, resolve per item, then afterWrite and respond. The write-back commits before the response — or its deliberate absence — leaves the process, which is what makes a timeout that landed distinguishable from one that did not.
