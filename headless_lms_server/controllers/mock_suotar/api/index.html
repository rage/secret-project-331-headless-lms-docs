The moocfi endpoints, one stage boundary at a time.

Order per request, as Suotar’s middleware runs it: the JSON body parse (size, then syntax), the credential, the envelope and item validation, the item-keyed load, the auth/requestGate/ parse faults, resolve request-level then per item, then afterWrite and respond. The write-back commits before the response — or its deliberate absence — leaves the process, which is what makes a timeout that landed distinguishable from one that did not.
