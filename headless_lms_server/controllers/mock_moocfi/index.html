Module mock_moocfi 

Source
Expand description

Mock mooc.fi: a stand-in for mooc.fi’s delegated credit registration routes, and the control surface tests seed it through.

Mounted at /api/v0/mock-moocfi only when TEST_MODE and USE_MOCK_MOOCFI_ENDPOINT are both on. State is in memory, shared by the server’s workers and lost on restart, so a test seeds what it reads. Serves:

  • GET api/delegated-completions/{course_id}/users/{upstream_id}, GET api/delegated-courses/{course_id} and POST api/register-completions, as mooc.fi does, behind the mock organization secret;
  • [en/]register-completion/{slug}, a stand-in for mooc.fi’s registration page whose button mints a handoff through api/credit-registration-handoff/{slug} as mooc.fi’s backend does;
  • [en/]credit-registration-handoff/, a stand-in for mooc.fi’s landing for handoffs from courses, which redeems the token through api/courses-handoff/redeem as mooc.fi’s backend does;
  • control/... to seed completions, set whether a course has a certificate, read the recorded report-back calls, simulate an outage and forget one student.
