Handlers for HTTP requests to /api/v0/moocfi/outbound-handoffs.

The other direction from super::credit_registration_handoffs: a student leaving courses for mooc.fi carries a token minted by crate::controllers::main_frontend::credit_registrations::create_my_moocfi_handoff, and mooc.fi’s backend redeems it here to learn whom to sign in and where to send them.
