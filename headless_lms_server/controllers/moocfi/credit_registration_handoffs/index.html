Handlers for HTTP requests to /api/v0/moocfi/credit-registration-handoffs.

mooc.fi’s backend mints a handoff here when a student presses “Register in courses.mooc.fi”, and sends the student’s browser to the returned URL, where crate::controllers::main_frontend::moocfi_handoffs signs them in. The handoff itself is not stored, though a student new to courses gets an account as on login, and no completion is read from mooc.fi here.
