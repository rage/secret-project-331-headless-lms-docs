Module moocfi_handoffs 

Source
Expand description

Handlers for HTTP requests to /api/v0/main-frontend/moocfi-handoffs.

The student’s browser arrives at redeem by a top-level navigation from mooc.fi’s credit registration page, or from Elements of AI’s, carrying a handoff minted by crate::controllers::moocfi::credit_registration_handoffs. Every answer to the navigation is a 303, never JSON:

  • the right account signed in: on to the registration page;
  • nobody signed in, arriving same-site from mooc.fi’s own page: signed in, then on to the registration page;
  • another account signed in, or any other arrival: to the course’s landing page (/completion-registration/mooc-fi/{moocfi_course_id}/handoff), with a single-use continuation in an HttpOnly cookie that continue completes once the student confirms. Nobody is signed in without asking on a navigation another site could have started, which would allow login CSRF;
  • a handoff for an account with any courses role, and anything else: to the normal login, which never signs anyone in.

A handoff is single use: signing in or starting a continuation spends it. Sessions it signs in are delegated; see authentication::remember.
