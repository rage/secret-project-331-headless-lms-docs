Moves one row back to ready_to_submit, in the caller’s transaction.

from_state is the state the refusals above were judged against; the transition refuses to overwrite the row if the pipeline has since moved it on. Does not make the row due: the single-row caller does that itself right after, and the bulk caller batches it over every row it retried instead of one UPDATE per row.
