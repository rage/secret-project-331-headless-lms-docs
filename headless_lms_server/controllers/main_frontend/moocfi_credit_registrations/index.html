Handlers for HTTP requests to /api/v0/main-frontend/moocfi-credit-registrations.

The mooc.fi registration page’s data: the signed-in student’s completions of one mooc.fi course, read from mooc.fi on every load. Per-registration detail is behind the routes keyed on a completion’s external_completion_id, which only completions courses registers have.
