UserListSearch
Search box filter for user lists: every word of the search appears in the name or email, in any order, or the whole search is a near match for a misspelled name or email. Queries apply it as (ud.name_search_helper || ' ' || ud.email_search_helper) LIKE ALL ($word_patterns) OR word_similarity($misspelling_term, ud.name_search_helper || ' ' || ud.email_search_helper) >= 0.5. search_for_user_details_fuzzy is the ranked search over all users.
