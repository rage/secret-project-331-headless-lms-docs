Module student_number 

Source
Expand description

Catching typos in a student number a person types: today’s University of Helsinki numbers are a 0 and eight digits, the last a check digit.

Only for typed input. A number from Sisu or Suotar is an opaque identifier and is taken as it comes, since Sisu may change the format.
