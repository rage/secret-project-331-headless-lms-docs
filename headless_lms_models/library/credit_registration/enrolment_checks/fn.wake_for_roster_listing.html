Wakes the rows of this module or mooc.fi target waiting for an enrolment when the roster lists their student under an enrolment id the row has not seen, stopped rows included, and returns how many it touched.

A row never checked has seen nothing, so any listing wakes it. The listed ids count as seen afterwards, so one listing wakes a row once. Replaced rows are left alone. Only the clock moves: the enrolment is still resolved by a check, not read off the roster. Unless ignores_test_holds, rows under a test-exclusive hold are left alone, as an unscoped claim leaves them.
