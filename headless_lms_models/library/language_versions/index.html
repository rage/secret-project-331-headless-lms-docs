Module language_versions 

Source
Expand description

The language-version repair tool: detects and fixes wrong links between the language versions of a course and their pages and exercises.

Modules§

counterpart
Creates a missing counterpart: copies a page with its exercises into another language version and links the copy to the page and its exercises to theirs.
counterpart_index 🔒
Lookups over a LanguageGroupSnapshot shared by detection, suggestions and the structure comparison.
detection
Detects what is wrong with the links between a course’s language versions.
dismissals
Problems a teacher marked as intended (“Mark as intended”).
join_candidates
Courses outside a course language group that could join it as language versions.
linking
Links and unlinks pages and exercises across language versions by moving them between page and exercise language groups. Links never change content or points.
membership
Joins a course into a course language group and splits one off, moving the per-group student data with it. Per-course data (completions, course instance enrolments, exercise states, points) stays with the course and needs no moving.
operation_logs
The log of changes made with the language-version repair tool. There is no undo; the log lets a mistake be repaired by hand.
snapshot
Everything the repair tool reads about a course language group, loaded in one go so that detection, suggestions and the structure comparison work on the same state.
structure
The language versions side by side: chapters by number, linked pages and exercises on rows.
suggestions
Suggested counterparts for a course’s pages and exercises in the other language versions.
types
Request and response types of the language-version repair tool’s API.
