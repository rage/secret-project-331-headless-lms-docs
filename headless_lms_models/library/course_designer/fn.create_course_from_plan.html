Expand description

Creates a draft course from the plan’s Design course structure: one chapter per planned chapter, each with an Introduction page, one page per topic and a Conclusion page. The creator becomes a teacher on the course and the plan remembers the course.

The caller must have checked that user_id may create courses in the organization. Fails if the user is not a plan member or the plan already has a course.
