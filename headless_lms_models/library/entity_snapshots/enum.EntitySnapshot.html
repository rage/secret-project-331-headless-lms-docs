Enum EntitySnapshot 

Source 
pub enum EntitySnapshot {
    Page(PageSnapshot),
    Chapter(ChapterSnapshot),
    Module(ModuleSnapshot),
    CourseSettings(CourseSettingsSnapshot),
    GlossaryTerm(GlossaryTermSnapshot),
    Reference(ReferenceSnapshot),
    CourseDefaultReviewConfig(CourseDefaultReviewConfigSnapshot),
}
Expand description

A snapshot of any entity type an agent changeset can hold. Serialised as the bare snapshot; stored ones are parsed with EntitySnapshot::from_json, which knows the type.
