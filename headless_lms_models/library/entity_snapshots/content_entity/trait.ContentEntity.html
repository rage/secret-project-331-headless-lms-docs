Expand description

What models know about one kind of content entity, implemented by its snapshot type, so that code over every kind dispatches on ContentEntityType once.

async fn lock_rows(conn: &mut PgConnection, ids: &[Uuid]) -> ModelResult<()>

Locks the entities’ rows until the transaction ends. Soft-deleted rows are locked too: a publish can restore them. ids must be sorted, so that concurrent lockers take the rows in the same order.
