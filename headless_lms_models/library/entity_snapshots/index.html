Module entity_snapshots 

Source
Expand description

Full snapshots of course content entities.

Agent changesets stage these, entity_history stores them, and publishing and restoring write them back through the existing save paths. A snapshot holds every field its save path writes, so writing back an unchanged snapshot is a no-op.
