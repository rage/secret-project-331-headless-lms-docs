Functions§

discard
Drops every staged change of an open changeset. With reviewed_revision, refuses if the changeset is at another revision, so that changes staged after the user looked are not dropped unseen.
discard_entities
Drops the entities from an open changeset, so the user sees them live again, classifies the risk of the rest again and returns the entities it dropped. Entities the changeset doesn’t have are skipped. Refuses like discard, and if the rest would break rules of publishing the whole changeset didn’t.
lock_open_changeset 🔒
Locks the changeset until the transaction ends and checks that it is open and, with reviewed_revision, still at that revision.
