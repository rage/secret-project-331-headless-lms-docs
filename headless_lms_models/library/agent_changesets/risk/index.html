Module risk 

Source
Expand description

Risk rules: which staged changes only the user may publish, on the review page.

Only live content is risky. Draft and test-mode courses, hidden pages and chapters that haven’t opened yet are free. Size alone never makes a change risky, and moving exercises never does: an exercise’s deadline counts only when its own deadline field changes.

Risk belongs to the whole changeset against the live course, so it is judged on every staged entity at once: an exercise moved off its page by one call and removed by another is still a removal.
