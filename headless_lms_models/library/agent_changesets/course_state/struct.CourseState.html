Expand description

Every editable entity of one course.

§exercises: Option<BTreeMap<Uuid, ExerciseRecord>>

By exercise id; None until CourseView::load_exercises or CourseView::load_exercises_on_pages (only those pages’) loads them.

By exercise id; loaded with the pages. Entries of exercises no page holds any more stay.
