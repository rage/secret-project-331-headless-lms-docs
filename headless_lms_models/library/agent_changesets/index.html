Module agent_changesets 

Source
Expand description

Staging, publishing and reverting AI agent changes to course content.

Every agent write is staged into the user’s open changeset for the course (see stage_call); reads of the staged state overlay the changeset on the live content (see course_state::load_view); publish writes the changeset through the web UI’s save paths.
