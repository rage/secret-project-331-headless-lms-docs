Expand description

The slide of each exercise that the course site shows the user: the one already selected for them in course_id, otherwise a random one, as for anonymous visitors. Read-only: unlike crate::exercises::get_or_select_exercise_slide, a random pick isn’t stored, so it can differ between calls. Exercises without slides are left out.
