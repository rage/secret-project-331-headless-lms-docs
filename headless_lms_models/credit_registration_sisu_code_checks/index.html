Module credit_registration_sisu_code_checks

Whether Sisu holds a course code for a student, for the codes no ledger row of theirs is under: the equivalent older codes of a mooc.fi code, and a code’s prerequisite with its equivalents. Asked by resolve-enrolments; read by the prerequisite gate and when a row is resolved.
