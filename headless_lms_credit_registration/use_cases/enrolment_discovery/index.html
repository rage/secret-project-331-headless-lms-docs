Module enrolment_discovery 

Source
Expand description

The enrolment-discovery phase: who the study registry says is on the course.

Each iteration lists the course codes that are due, triggered listings first, in batches as large as the registry takes; every module on a code shares its listing. One listing wakes the registrations of people we already have a link for and, while account linking is switched on, claims an account-linking mail for everybody else. When to list a code is [headless_lms_models::credit_registration_roster_schedules].
